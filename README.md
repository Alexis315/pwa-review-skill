## 🎯 What Is beads_bend?

beads_bend is a friendly, powerful tool that helps you keep track of tasks, bugs, and ideas — especially when you're working with AI coding agents. Think of it as a smart to-do list that remembers everything, works entirely on your computer (no internet needed), and never loses your data.

It's a new version of a well-tested program called "beads" (originally written in a language called Rust). This version is written in a brand-new language called "Bend 2", which makes it faster and more reliable. Every time we change something, we automatically check that it still works perfectly compared to the original — so you can trust it.

**Who is this for?** Anyone who wants a simple, private way to manage projects, especially if you use AI tools to help write code. No programming knowledge required.

## ✨ Key Features

Here's what makes beads_bend so useful:

### 📝 Dependency-Aware Task Tracking
- Add tasks and mark which ones depend on others. If Task B can't start until Task A is done, beads_bend remembers that for you.

### 🔒 Local-First Privacy
- All your data stays on your computer. No cloud, no accounts, no tracking. Your information is yours alone.

### 🤖 Built for AI Agents
- If you use AI coding tools (like GitHub Copilot or ChatGPT to write code), beads_bend helps you organize what the AI should do next.

### ✅ Golden-Tested Reliability
- Every update is checked against the original version to make sure nothing breaks. You get a polished, tested tool every time.

### 📄 Simple JSONL Storage
- Your tasks are saved in a simple, open format (JSONL). This means you can read and back up your data easily, or move it to another tool if you ever want to.

### ⚡ Fast and Lightweight
- Because it's written in the Bend 2 language, it runs quickly and uses minimal memory.

## 📚 How to Use beads_bend

Here's a quick guide to your first session:

1. **Start a new list** – When the program opens, you'll see an empty list. Type your first task in the box at the top and press Enter.
2. **Add details** – Click on any task to add notes, labels, or due dates.
3. **Create dependencies** – Drag one task onto another to say "this task can't start until that one is done."
4. **Mark complete** – Click the checkbox next to a task when you're done.
5. **Save automatically** – Everything saves as you go. You can close the window and reopen it later — your tasks are still there.

## 🛠️ Troubleshooting Tips

If something isn't working, try these simple fixes:

### Program won't open
- Make sure you extracted the ZIP file completely (not just opened it).
- Check your Downloads folder — some browsers save files in unusual places.
- Try right-clicking the .exe file and choosing "Run as administrator".

### Window opens but is blank
- Close the program and reopen it.
- Make sure no other window is covering it.

### I can't see my old tasks
- beads_bend saves data in the same folder as the program. If you moved the program, the data moved with it. Look for a file called `tasks.jsonl` in the program folder.

### I want to uninstall
- Simply delete the folder where you extracted the program. There's no installer, so nothing else to remove.
